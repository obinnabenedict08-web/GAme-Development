SkyRunner Game

A simple 2D game project developed using the *Godot Engine* as part of Week 1 of the Game Development activity.

The purpose of this project is to set up a basic Godot game, understand the fundamental building blocks of Godot, and establish a clean GitHub repository with version control.

         Project Overview

This project is the initial setup for a 2D mini-game. It demonstrates the basic structure of a Godot project, including:

- Creating a Godot project
- Creating and managing scenes
- Using nodes and 2D sprites
- Running a basic 2D scene
- Setting up Git and GitHub
- Using .gitignore
- Configuring Git LFS for large files
- Maintaining project documentation

The project will serve as the foundation for developing the complete mini-game in later activities.

          Learning Objectives

By completing this project, the following concepts are practiced:

- Understanding *Godot nodes*
- Understanding *Godot scenes*
- Understanding *signals*
- Creating a basic 2D game scene
- Using Git for version control
- Creating and managing a GitHub repository
- Using Git LFS for large assets
- Writing project documentation using Markdown
